About This Project

A terminal clock. That's it.

Vibecoded in an afternoon while studying a subject that somehow makes you want to stare at anything except the actual slides. ClockTerm lives in your terminal, tells you the time in giant ASCII blocks, and asks absolutely nothing of you in return.

No notifications. No tabs. No "you might also like". Just the cruel, unstoppable passage of time, rendered — right there in your face. Quietly judging you for opening a new browser tab anyway.

What It Does

  • Displays the current time in 24-hour format in large ASCII art blocks
  • Shows seconds in a smaller font to the right of the main time
  • Displays the current date at the bottom of the screen
  • Adapts to your terminal size — always perfectly centered

How to Run It

No dependencies. No setup. No 47-step installation guide. Just Python and a terminal: 

git clone https://github.com/riccardomasetti/clockterm
cd clockterm
python3 clock.py

Works on any terminal. Type q or press Ctrl+C to exit (if you ever decide to go back to studying).
